# 主持人一页操作单

1. 彩排时先从活动详情进入会场，点击「创建独立彩排场次」，让成员进入同一彩排实例。正式活动直接从活动详情进入。核对开场时间、接班人和替补。请每个人从自己的账户签到，打开「入场前测试设备」。成员自己选择是否自动转场。姓名默认标注「本人声明」，运营完成核验后才能标记为已核验。
2. 创业快闪可在「快闪团队编组」一键全选成员并分发。检查每组的 idea 发起人、Builder、Seller 和总人数，必要时拖动姓名或勾选后指定团队。确认发布，再点击「开始所有创意组讨论」。正在讨论时调人，先告知原组将短暂重连。
3. 点击「共享演示与主持人声音」，选择演示窗口并授权麦克风。现场接收者必要时点击「播放声音」。调度台列出各组演示源信号，房内成员还须实际听看确认。
4. 勾选目标组，核对预览后立即交棒或倒计时 30 秒。接班人离线时先选替补或暂代。通知只发文字。恢复演示及全场召回会终止受影响会谈，确认前查看参与者和范围。
5. 先看超时和求助。点开该组的下一位及更新时间，联系状态待确认的人。成员可登记补谈，管理员可申请补位。正常入场从个人议程操作。提前开始要求双方先结束上一场并分别同意。成员可以随时跳过或离场。
6. 结束后由双方处理补谈或试合作意向。女性共创的建队仍经过原活动的邀请、接受和运营审核。通过后进入主站团队工作台。

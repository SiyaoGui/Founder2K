# Founder2K 的项目、机会与女性共创

2026-11-21。资源条目由 Founder2K 统一维护。女性共创提供女性创业者相关的专题视图，并保留访问全库的入口。快闪按项目阶段引用同一资源。已有收藏沿用同一账户与机会编号。

## 三个入口分别帮助谁作什么决定

| 入口 | 用户带来的问题 | 关键动作 | 可带走的成果 |
|---|---|---|---|
| 创业快闪 | 一周内哪件事值得验证？ | 开场选择假设与证据标准，在线协作，现场演示，结项评审 | 原型、用户反馈、贡献记录和下一轮缺口 |
| 资源库 | 我需要钱、导师、场地、伙伴还是一次路演？ | 对照地区、主体资格、机会类型、窗口、材料与出处，收藏合适机会 | 可比较的机会清单及一项补材料任务 |
| 女性共创 | 谁愿意和我一起完成这一轮？ | 找共创者或导师、讨论材料、征得同意后联系投资人，使用女性专题视图 | 有明确分工的合作关系与可复用的同伴经验 |

## 一期的实际用法

一位做 AI 硬件的女性创始人可先在女性共创寻找试用伙伴。她用快闪完成可演示原型与三次用户观察，在结项时列明是否已有公司、数据和联合申请人。随后用资源库筛选硬件比赛、孵化器及女性专项。申请缺少现场验证，就将它写进下一次快闪或 Callback；需要导师看 pitch，就回女性共创发一条具体请求。本人同意后可以把去身份化的经验回填到讨论区。

主站维护来源、版本、地区、申请条件、金额和时间。专题标签是发现线索，真实资格以当期主办方条件为准。个人报名进度只属于各自项目。草创团队、成熟团队、大学研究者和跨国联合体的条件应分别判断。

## 运营与验收

来源是创办人提供的 210 张融资日历底稿。区分机会、历史轮次、研究汇总和资料缺失。保留预计时间和日期类型，个人倒推的目标日、申请决定与私联信息不进入共享目录。核验来源时分别记录项目身份与当期截止；单次网页核对不代表全库已核实。

每月由资源维护人复核临近窗口，由快闪主持人记录结项后选了什么资源、缺哪项证据，由女性共创主持人回访一次有效的引荐或材料反馈。试点指标分别记录完成用户测试的团队比例、收藏后核实资格并递交的项目比例、交流后有明确下一步的请求比例。以上是建议采集的指标。

## 网站入口与数据口径

| 入口 | 已接入的功能 |
|---|---|
| [主站资源库](https://founder2k.com/#opportunities) | 按名称、资料关键词、地区、资助类型、资格筛选。切换融资日历查看月份、截止日、预计窗口和历史场次。旧链接 `#resources` 仍可使用。 |
| [女性创业机会](https://founder2k.com/#women/resources) | 从主站数据选取有女性创业支持线索的记录。专题支持收藏、查看来源、进入社群讨论，也可以返回完整目录。 |
| [创业快闪](https://founder2k.com/#sprints) | 从快闪进入资源库，活动场次单独管理。 |
| [项目工作台](https://founder2k.com/#teamspace) | 收藏跟随个人账户。成员可选择自己的团队，把资源链接和缺少的申请材料保存为项目进展。 |

导入日历的 210 条记录包括独立机会、批次和研究索引，其中 168 条有来源链接，86 条带有合计 120 个日历节点。12 条具有女性创业相关标签。与原有目录中重叠的 3 条复用旧编号，保留另外 2 条既有资料，形成 212 条基础资料。运营以后发布的资料另行计入。主办方来源核对日期独立于文件导入日期。

网站源码维护人更新 `app/funding-calendar.json` 时，应保留机会编号，以便以前的收藏和团队记录还能打开。每条资料可有多组资格或资金条款，以及多个带时间范围和预计标志的节点。过期场次可按时间回查。运营后台可以勾选女性创业专题，让新条目同时出现在两个入口。团队申请记录与公开资源条目分开保存。

本轮使用本机测试账户检查了 12 条一页的目录、筛选和空结果、跨入口收藏、项目成员写入及重读申请材料缺口、旧链接，以及 390 像素宽手机上的日历与详情。示例资料入口包括 [欧洲女性创新者奖](https://founder2k.com/#opportunities?id=cal-eu-656131)。

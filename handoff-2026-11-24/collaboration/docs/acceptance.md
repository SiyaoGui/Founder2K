# 本轮验收与接手入口

证据分三层。角色评估来自设计走查，交互结果来自本机浏览器和临时测试身份，线上交付由生产部署回执确认。九类真实参与者的现场观察仍待首期进行。

| 用例 | 操作 | 预期及本轮结果 |
|---|---|---|
| 首页任务 | 逐个切换九种身份 | 每种身份显示目标、三个步骤、主操作和关联入口。桌面与手机通过。 |
| 投资与导师 | 看授权展品、按主题找人或进入求反馈讨论 | 展品支持独立定位、按领域筛选、验证摘要与所需协助。目录和讨论支持带筛选条件进入。真实引荐待验证。 |
| 创业者与参与者 | 从首页进入真实场次或团队项目 | 保留申请、审核、单独的私人草稿、团队提交与展示审批。运营新建场次及 13 个主要页面回归通过。 |
| AI 与非 AI | 在同一硬件主题分别建立两种周期 | 非 AI 报名无会员问题；AI 正式报名漏确认时服务端拒绝。通过。旧场次按原资格说明显示。 |
| 旁听 | 在 AI 场次改选旁听 | 隐藏正式参与者会员问题，旁听申请可提交。原有旁听名额和投票限制继续由服务端处理。 |
| 销售与开发 | 分别进入市场和原型记录，写入、刷新 | 服务端保存到对应团队。两次刷新后都能读回所填的阶段成果。通过。真实分账另行核对。 |
| 移动端 | 390 像素宽度使用首页及七个工作页面 | 未发现横向溢出。资源地区筛选、无结果、课程进度和运营表单通过。 |

## 下一次协作可直接领取的任务

- **开场主持**。将 pitch、idea 投票、落单成员二次匹配落到同一场次。先定弃权、平票、匹配失败和人工改组规则，再用三支模拟团队验收。
- **线下签到**。分开保存工牌称呼、照片使用范围、可参加环节与到场状态。验收撤回摄影授权和临时缺席后的旁听比例。
- **销售与奖项**。为同币种的已收款、退款、直接成本和成员书面约定建立对账流程。先实现可追溯的复核与更正，再讨论自动结算。
- **投后联系与导师跟进**。在成员同意后把一次引荐关联到具体展品，记录是否回应及下一步。团队撤回展示后，检查公开页面和推荐列表。
- **试点验证**。按九种路径记录真正无法完成的步骤，优先修复多人遇到的同一断点。访谈时区分用户经验、浏览器复现和运营规则。
